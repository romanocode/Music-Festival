# Festival de Música

Proyecto  con HTML, CSS, SASS y Gulp. Es una página web de un festival  Techno y EDM que muestra secciones de lineup, galería y boletos.

## Qué incluye

- `index.html`: estructura de la página.
- `src/img/scss/`: estilos escritos en SASS.
- `build/css/app.css`: CSS generado.
- `gulpfile.js`: tarea para compilar SASS y copiar JS.
- `package.json`: dependencias de Gulp y Sass.

## Para qué sirve

Este proyecto sirve para aprender a trabajar con SASS y Gulp en un sitio web sencillo. También practica la organización de archivos y el flujo de compilación desde `src` hasta `build`.

## Tecnologías usadas

- HTML
- SASS (SCSS)
- Gulp
- Node.js / npm

## Cómo usarlo

1. Instalar dependencias:

```bash
npm install
```

2. Iniciar el modo de desarrollo:

```bash
npm run dev
```

3. Abrir `index.html` en el navegador.
